# Triage Labels

工程技能使用以下五个标准角色；执行时使用对应的实际标签。

| 标准角色 | 实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交由自主运行的 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时，使用上表映射后的标签。若项目已有其他标签命名，修改“实际标签”列；不要修改标准角色，也不要创建含义重复的标签。
